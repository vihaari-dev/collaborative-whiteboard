3. Formats of the project title page and certificates given in this handout should be strictly adhered to.

4. Submit each of the following at the time of final report submission:
   1. Four Spiral-bound copies of your Real-Time/Field-Based Research Project (One for the library and one per student in the group).

Each chapter shall begin on a new page. The six chapters are:

1. Introduction
2. Literature Survey
3. Requirement Analysis
4. Design
5. Implementation and Testing
6. Conclusion

### Section & Sub-section Numbering

- **Section titles:** Numbered as `2.1`, `2.2`, etc. — Bold and UPPER CASE. The first digit represents the chapter number; the second digit represents the topic title number.
- **Sub-section titles:** Numbered as `1.1.1`, `1.1.2`, etc. — Bold and Title Case. The first digit = chapter, second = section, third = sub-section.
